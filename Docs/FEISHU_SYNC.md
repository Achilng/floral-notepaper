# 飞书云同步配置

花笺采用本地优先的单向同步：笔记始终先保存到本地 Markdown 文件，再在后台同步到飞书新版文档。网络或飞书服务异常不会阻止本地保存。

## 准备飞书应用

1. 在[飞书开放平台](https://open.feishu.cn/app)创建企业自建应用。
2. 在权限管理中开通“创建及编辑新版文档”（`docx:document`）权限。
3. 创建并发布一个应用版本，使权限生效。
4. 从“凭证与基础信息”复制 App ID 和 App Secret。
5. 如需同步到指定文件夹，还要开通“查看、评论、编辑和管理云空间中所有文件”（`drive:drive`），并再次创建、发布应用版本，然后从文件夹链接中复制 folder token。

“添加文档应用”只适用于给既有的单篇云文档授权；文件夹界面可能没有该入口。

## 在花笺中连接

1. 打开“设置 → 飞书云同步”。
2. 填写 App ID、App Secret 和可选的文件夹 Token。
3. 启用飞书云同步，点击“测试连接”验证应用凭据。
4. 点击“登录飞书”，在浏览器中确认用户授权；授权页成功后返回花笺。
5. 点击“立即同步全部”完成首次上传。

App Secret 和飞书用户授权令牌使用操作系统提供的安全存储或用户级加密保护，不会以明文写入花笺的普通配置文件。App ID、文件夹 Token 和笔记到飞书文档的映射保存在本机。

## 同步行为

- 每篇本地笔记对应一篇飞书文档。
- 本地保存后等待约 5 秒，同一篇笔记的连续修改会合并后上传。
- 同步失败会自动重试两次；离线期间仍可正常保存本地笔记。
- 飞书端的修改不会下载到本地，并可能在下次同步时被覆盖。
- 删除本地笔记不会自动删除飞书文档，避免误删云端副本。
- 当前版本同步文字、标题、列表、待办、引用、代码块和分隔线；本地图片暂不会上传。

## 断开连接

关闭“飞书云同步”并保存即可停止新的后台上传。“清除密钥”会删除本机保存的 App Secret 和飞书用户授权令牌，但不会删除已经创建的飞书文档。
