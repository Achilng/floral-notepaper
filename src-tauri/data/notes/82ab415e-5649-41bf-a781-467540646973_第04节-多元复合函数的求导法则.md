# 第四节 多元复合函数的求导法则

## 🎯 知识点

### 一、链式法则（核心！）

**情形1**：$z=f(u,v),\ u=u(t),\ v=v(t)$
$$\frac{{\rm d}z}{{\rm d}t}=\frac{\partial z}{\partial u}\frac{{\rm d}u}{{\rm d}t}+\frac{\partial z}{\partial v}\frac{{\rm d}v}{{\rm d}t}$$

**情形2**：$z=f(u,v),\ u=u(x,y),\ v=v(x,y)$
$$\frac{\partial z}{\partial x}=\frac{\partial z}{\partial u}\frac{\partial u}{\partial x}+\frac{\partial z}{\partial v}\frac{\partial v}{\partial x}$$
$$\frac{\partial z}{\partial y}=\frac{\partial z}{\partial u}\frac{\partial u}{\partial y}+\frac{\partial z}{\partial v}\frac{\partial v}{\partial y}$$

**情形3**：$z=f(u,x,y),\ u=u(x,y)$（半抽象函数）
$$\frac{\partial z}{\partial x}=f_u\cdot\frac{\partial u}{\partial x}+f_x$$

## 📝 典型例题

**例1**：$z=\sin(u+v),\ u=t^2,\ v=e^t$，求 $\dfrac{{\rm d}z}{{\rm d}t}$。
**解**：$\dfrac{{\rm d}z}{{\rm d}t} = \cos(u+v)\cdot2t+\cos(u+v)\cdot e^t = (2t+e^t)\cos(t^2+e^t)$

**例2**：$z=f(xy,x^2+y^2)$，求 $z_x,\ z_y$。
**解**：设 $u=xy,\ v=x^2+y^2$
$z_x = f_u\cdot y + f_v\cdot 2x$
$z_y = f_u\cdot x + f_v\cdot 2y$
